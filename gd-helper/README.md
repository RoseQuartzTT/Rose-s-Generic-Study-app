# Rose's Flashcard Gate (Geode mod)

Counts Geometry Dash attempts for Rose's Annotations' flashcard breaks.

## Building it (free, no software to install)

1. Make a GitHub repository and upload everything in this folder, including the hidden `.github` folder.
2. GitHub builds it automatically. Open the repository's **Actions** tab, click the newest run, and download the artifact **rose.flashcard-gate** when it finishes (about 5 minutes).
3. Unzip it to get `rose.flashcard-gate.geode`.
4. In Rose's Annotations, open **Flashcard games** while Geometry Dash is running and click **Install helper mod from a file…**, then choose that `.geode` file. Restart Geometry Dash.

Requires Geode installed in Geometry Dash (https://geode-sdk.org). Built for Geode 5.10 and Geometry Dash 2.2081; if Geometry Dash updates, change the versions in `mod.json` to match and let it build again.
